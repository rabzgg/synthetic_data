# Parameter mapping

_Generated by `python3 cli/parameter_mapping.py` from `core/quantities/`; do not edit by hand._

How a datasheet becomes a simulated reading: the **quantity catalog** says what can be measured, the **model parameters** are the one generic way every sensor measures, and the **normalisation rules** turn datasheet wording into those parameters.

## Model parameters

Every parameter in a part file is `{value, unit, source}`; `source` starts with `datasheet` or `ASSUMPTION`. Units are converted to the quantity's unit (`q` below).

| parameter | unit | default | meaning |
|---|---|---|---|
| `range` | q | required | [low, high] the sensor can report; required |
| `resolution` | q | required | smallest reported step; required |
| `accuracy` | q | 0.0 | ± bound of the bias of one unit (absolute part) |
| `accuracy_pct_reading` | % | 0.0 | ± bound of the bias of one unit, in % of the reading |
| `accuracy_combine` | - | sum | how the two accuracy parts combine: sum (±(a + b %)) or max (whichever greater) |
| `noise_sd` | q | 0.0 | standard deviation of the white noise per sample |
| `noise_density` | q/√Hz | — | noise spectral density; noise_sd = noise_density × √bandwidth_hz |
| `bandwidth_hz` | Hz | — | measurement bandwidth, used with noise_density |
| `t90_s` | s | 0.0 | time to reach 90 % of a step; 0 = instant |
| `t90_up_s` | s | — | t90 for a rising input (default t90_s) |
| `t90_down_s` | s | — | t90 for a falling input (default t90_s) |
| `hysteresis` | q | 0.0 | full width of the hysteresis band |
| `drift_per_hour` | q/h | 0.0 | ± bound of the linear drift rate of one unit |
| `deadband` | q | 0.0 | values within ±deadband of deadband_center are reported as deadband_center |
| `deadband_center` | q | 0.0 | centre of the deadband (e.g. 0 for a toxic gas, 20.9 for O2) |
| `cross_sensitivity` | cross | — | {quantity: {factor, ref}}: adds factor × (other − ref) to the input |

## Order of the stages

```
0. cross-sensitivity   interfering quantities are added to what the sensing element sees
1. response            first order, time constant tau = t90 / ln(10)
2. bias + drift        one bias per unit and axis, drawn once within ±accuracy; drift grows linearly
3. noise               white Gaussian, sd per sample
4. hysteresis          play operator: the output lags a reversal by up to hysteresis / 2
5. deadband            values within ±deadband of deadband_center read as deadband_center
6. quantisation        to the resolution
7. clip                to the range; over_range / under_range flag what was cut off
```

## Normalisation rules

| rule | the datasheet says | maps to | conversion | example | assumption |
|---|---|---|---|---|---|
| `range` | Measurement range 0 … R, or lo … hi | range | taken as is | Relative humidity: [0, 100] %RH → range = [0, 100] %RH | — |
| `range_symmetric` | Full scale ±R (e.g. ±16 g) | range | [−R, +R] | Acceleration: 16 g → range = [-16, 16] g | — |
| `resolution` | Resolution X; LSB size X | resolution | taken as is | Hydrogen sulfide: 0.1 ppm → resolution = 0.1 ppm | — |
| `sensitivity_lsb` | Sensitivity S LSB/unit (digital sensors) | resolution | resolution = 1 / S | Acceleration: 1024 LSB/g → resolution = 0.000976562 g | — |
| `bits` | N-bit output over a span | resolution | resolution = span / 2^N | Air pressure: 16 bit over 300 … 1100 hPa → resolution = 0.012207 hPa | — |
| `accuracy` | Accuracy ±X; tolerance ±X; max. error ±X; absolute accuracy ±X | accuracy | bias of one unit drawn uniformly in ±X, fixed for the whole run | Air temperature: 0.5 °C → accuracy = 0.5 °C | — |
| `accuracy_pct_reading` | Accuracy ±Y % of reading | accuracy_pct_reading | bias drawn in ±Y % of the current value (a gain error) | Carbon monoxide: 5 % → accuracy_pct_reading = 5 % | — |
| `accuracy_pct_fs` | Accuracy ±Y % of full scale (FS) | accuracy | accuracy = Y / 100 × FS | Carbon monoxide: 2 ppm (full_scale=500) → accuracy = 10 ppm | — |
| `accuracy_sum` | Accuracy ±(X + Y % of reading) | accuracy, accuracy_pct_reading, accuracy_combine = sum | bound = X + Y % × \|value\| | Carbon dioxide: ±(30 ppm + 3 % of reading) → accuracy = 30 ppm, accuracy_pct_reading = 3 %, accuracy_combine = sum | — |
| `accuracy_max` | Accuracy ±X or ±Y % of reading, whichever is greater | accuracy, accuracy_pct_reading, accuracy_combine = max | bound = max(X, Y % × \|value\|) | Hydrogen sulfide: ±2 ppm or ±10 % of reading → accuracy = 2 ppm, accuracy_pct_reading = 10 %, accuracy_combine = max | — |
| `accuracy_typical` | Typical accuracy ±X, no maximum given | accuracy | used as the bound | Air pressure: 1.0 hPa → accuracy = 1 hPa | A typical value is not a guaranteed bound; real units can be worse. |
| `noise_rms` | Noise X RMS; noise sd X; 1σ X | noise_sd | taken as is | Air temperature: 0.02 °C → noise_sd = 0.02 °C | — |
| `noise_pp` | Noise X peak-to-peak | noise_sd | noise_sd = X / 6.6 | Acceleration: 0.66 mg → noise_sd = 0.0001 g | Gaussian noise; 99.9 % of samples within ±3.3 sd. |
| `noise_density` | Noise density D per √Hz | noise_density, bandwidth_hz | noise_sd = D × √bandwidth; without a bandwidth, bandwidth = ODR / 2 | Acceleration: 150 µg/√Hz (bandwidth_hz=100) → noise_sd = 0.0015 g | Only when the datasheet gives no bandwidth: ODR / 2 (Nyquist). |
| `repeatability` | Repeatability ±X (no σ stated) | noise_sd | noise_sd = X / 2 | Relative humidity: 0.2 %RH → noise_sd = 0.1 %RH | ±X read as ±2 sd (95 %). |
| `t90` | Response time T90 (t90) | t90_s | taken as is; first order, tau = T90 / ln 10 | Hydrogen sulfide: 15 s → t90_s = 15 s | — |
| `t63` | Time constant tau; T63 | t90_s | t90 = tau × ln 10 | Air temperature: 1 s → t90_s = 2.30259 s | — |
| `t50` | Response time T50 | t90_s | t90 = T50 × ln 10 / ln 2 | Carbon monoxide: 10 s → t90_s = 33.2193 s | — |
| `recovery_t90` | Recovery / fall time T90 (back to zero) | t90_down_s | taken as is | Carbon monoxide: 60 s → t90_down_s = 60 s | — |
| `drift` | Long-term stability / drift ±X per year (month, day) | drift_per_hour | unit conversion to per hour (year = 8760 h, month = 730 h) | Relative humidity: 0.25 %RH/year → drift_per_hour = 2.85388e-05 %RH/h | — |
| `hysteresis_pm` | Hysteresis ±X | hysteresis | full width = 2X | Relative humidity: 1 %RH → hysteresis = 2 %RH | — |
| `hysteresis` | Hysteresis X (difference between rising and falling) | hysteresis | taken as is | Relative humidity: 0.5 %RH → hysteresis = 0.5 %RH | — |
| `deadband` | Zero deadband / zero suppression X | deadband (deadband_center = 0) | values within ±X of zero are reported as zero | Carbon monoxide: 2 ppm → deadband = 2 ppm, deadband_center = 0 ppm | — |
| `temperature_coefficient` | Temperature coefficient X per °C (of offset) | cross_sensitivity to air.temperature_c | adds X × (T − T_ref) to the input | Air pressure: 0.01 hPa/°C (ref_c=25) → cross_sensitivity = air.temperature_c: factor 0.01, ref 25 | Reference 25 °C when the datasheet gives none. |
| `cross_gas` | Cross-sensitivity: C of gas G reads as R | cross_sensitivity to G | factor = R / C, ref 0 | Hydrogen sulfide: 6 ppm (gas=air.co_ppm, applied=300) → cross_sensitivity = air.co_ppm: factor 0.02, ref 0 | — |
